# Гомельский лототрон

Случайный выбор заведения с доставкой еды по Гомелю. Крутите барабан, и выпавший ресторан сразу открывается в меню для заказа. На отдельных вкладках собраны акции и сравнение, где заказать дешевле: в Яндекс Еде или напрямую у заведения.

Сайт статический: один `index.html` и картинки в `img/`. Данные собраны 20 октября 2026 года, акции и цены доставки со временем меняются.
